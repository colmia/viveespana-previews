# Vive España · Previews

Este repositorio contiene exclusivamente salidas frontend compiladas para
revisión visual. La fuente de verdad, el código editable, las decisiones y la
trazabilidad permanecen en el repositorio privado.

No contiene ni debe contener código del Grifo, Firebase Functions, GHL,
Firestore, secretos, datos personales o documentación operativa privada.

## Rutas

- `main/`: última versión aprobada e integrada.
- `pr-<número>/`: candidata de una pull request privada.
- `builds/<sha>/`: compilación inmutable de un commit.

El contenido de este repositorio es generado. No se aceptan Issues ni trabajo
manual de producto aquí.
